- نجح **Whisper Small متعدد اللغات** باستخدام `whisper.cpp v1.7.6` على CPU محلي.
- اكتشاف اللغة: **العربية**، احتمال اللغة `0.995830`. هذه ثقة **اللغة** وليست نسبة دقة النص.

- المخرجات: **34 مقطعاً و308 كلمات** بحدود زمنية تقديرية، مع نقاط محاذاة DTW.
- النص الناتج **تفريغ آلي غير معتمد للتسجيل بعد**؛ الأخطاء اللفظية أو الإملائية والتوقيتات الموسومة تحتاج مراجعة.

النتائج محفوظة بجوار الفيديو:

- `source.txt`: النص الخام، بدون استبداله بسكربت تجريبي.
- `source.srt`: المقاطع الزمنية.
- `source.segments.json`: النص وحدود الكلمات والثقة والتحذيرات وبصمة الفيديو والنموذج.
- `source.review.md`: حالة المراجعة والقيود قبل الدبلجة.

**لم يُولّد هذا التشغيل أي صوت.** مصدر الصوت في مرحلة الدبلجة التالية يبقى الوكيل، لا Edge أو VoxCPM أو XTTS.

## ما جُرّب فعلياً

1. تحميل `faster-whisper/small` محلياً: تعذّر اتصال TLS بـHugging Face. تثبيت الحزمة وحده لم يكن كافياً.
2. تشغيل مهمة ASR جديدة على GitHub Actions: رفض GitHub رفع ملف workflow لأن ربط التطبيق لا يملك صلاحية `workflows`. **لم تبدأ مهمة Actions**؛ هذا ليس إغلاقاً لجلسة GitHub.
3. نموذج Vosk الإنجليزي: استطاع التشغيل، لكن ناتجه غير صالح لهذا الصوت العربي. استُبعد؛ لم يُحفظ كتفريغ معتمد.
4. تنزيل أوزان Whisper Medium من GitHub Releases: بيانات الإصدار متاحة، لكن مضيف ملفات الإصدارات أعاد EOF.
5. **الطريقة الناجحة:** تحميل أجزاء نموذج GGML Small كملفات Git عادية، التحقق من كل جزء، ثم مقارنة النموذج المجمّع بالبصمة الرسمية قبل تشغيله محلياً.

مصدر الأجزاء مثبت بكوميت في `config/whisper-small-ggml.json`، وبصمة SHA-1 للنموذج تطابق جدول `ggml-org/whisper.cpp` الرسمي:

```
55356645c2b361a969dfd0ef2c5a50d530afd8d5
```

وتوجد SHA-256 مثبتة أيضاً. لا تُقبل ملفات Git LFS الوهمية كأوزان. الملفات الكبيرة داخل `.cache/` فقط، وليست في Git أو نتائج المشروع.

## إعادة التشغيل محلياً

من جذر المستودع؛ يجب توفر `gh` المتصل بـGitHub ومترجم C++ و`make`:

```bash
python3 -m venv .venv
.venv/bin/pip install imageio-ffmpeg cmake
.venv/bin/python scripts/bootstrap_local_whisper.py
.venv/bin/python scripts/transcribe_video.py \
  --backend whisper-cpp \
  --source library/snaptik-7614635067838598423-v3/source.mp4 \
  --output-dir output/asr
```

النموذج الافتراضي في هذا المسار هو GGML Small المثبت، وDTW مضبوط عليه. تشغيل `--model` لنموذج آخر يتطلب ضبط `--dtw-model` أيضاً. حدود الكلمات آلية تقديرية وليست ضماناً لمزامنة الشفاه.

لا تعتمد على بقاء `.cache/` أو `.venv/` بين الجلسات: السكربت يعيد تجهيز الأوزان والبناء، بينما النص وبصماته محفوظان في المستودع.

للتشغيل المعتاد عندما يكون Hugging Face متاحاً:

```bash
.venv/bin/pip install -r requirements-asr.txt
.venv/bin/python scripts/transcribe_video.py \
  --source library/snaptik-7614635067838598423-v3/source.mp4 \
  --model medium --output-dir output/asr
```

## GitHub Actions

القالب موجود في `docs/github-actions/transcribe.yml`. **ليس Workflow نشطاً وهو في مجلد docs.** عند الحاجة لإتاحة التنفيذ على GitHub، يجب أن يدعم الربط صلاحية تعديل workflows، ثم يُضاف القالب إلى `.github/workflows/transcribe.yml` على **فرع الجلسة نفسه**. لا تطلب أو تحفظ رموز دخول في المحادثة.

القالب يشغّل التفريغ فقط ويرفع TXT وSRT وJSON كـArtifacts. لا ينشئ صوتاً ولا ينشر Pages ولا يكتب إلى `main`. تشغيل push مقصور على `arena/01a07c92-dub`، ولا يحتاج دمج PR.
