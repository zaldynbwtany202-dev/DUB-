# مراجعة النطق واللهجة والتفريغ العربي

## التفريغ ليس النص المعتمد

```bash
python3 scripts/transcribe_video.py --source path/to/take.mp3 \
  --backend faster-whisper --language ar --dialect ar-EG \
  --output-dir work/PROJECT/qa/asr-run-01
```

`--dialect` **تلميح للمراجع البشري فقط**، وليس كشفًا للهجة من Whisper. يحفظ البرنامج الكلمات منخفضة الثقة أو التي لا يملك لها وقتًا صالحًا مع `null` وتحذير واضح؛ لا يخترع وقتًا بتوزيعها داخل الجملة. يحذر من المقاطع التي قد تكون هلوسة (احتمال عدم وجود كلام مرتفع)، ويضع `review_required=true`. إذا تغير ملف تفريغ موجود في المجلد نفسه، يرفض استبداله؛ افتح مجلد تجربة جديدًا واحفظ تصحيحات المستمع.

## مقارنة التسجيل بالنص المقصود

```bash
python3 scripts/review_arabic_take.py --text-file work/PROJECT/text/g004.txt \
  --audio work/PROJECT/takes/g004.mp3 \
  --asr-json work/PROJECT/qa/asr-run-01/source.segments.json \
  --dialect ar-EG --out work/PROJECT/qa/review-g004.json
```

لا تُقبل نتيجة تفريغ تخص ملفًا آخر: تُقارَن بصمة `SHA-256` للتسجيل مع مصدر تقرير ASR قبل إنشاء قائمة المراجعة. تُعرض الكلمات متعددة القراءة من `config/homonym-hazards.json` (مثل «قوتهم/قوّتهم») وأمثلة النطق المصري من `config/egy-pronunciation.json` **كاقتراحات فقط**، لا يُستبدل النص تلقائيًا ولا يُغيَّر صوت الفيلم. تقرير المراجعة دائمًا `listener_review_required`، ولا يُعاد الكتابة فوق تقرير قديم.

أصلحنا مقارنة كلمات ASR بحيث لا تُقسِّم الحركاتُ الكلمةَ الواحدة إلى أحرف منفصلة. لكن التطابق الكتابي، خصوصًا في الكلمات المتجانسة الرسم، **لا يثبت النطق ولا اللهجة**؛ استمع إلى التسجيل والأصل، ودوّن تصحيحًا مستقلًا للنص والتوقيت قبل اعتماد الدبلجة. في مسار `ar-EG` لا نطبّق تشكيل الفصحى آليًا على النص المصري؛ تبقى حركات المستمع التي كتبها كما هي.

لا تُستأنف دبلجة باتريك جين ولا يُغيَّر قفل صوتها بهذه الأدوات: اختيار الصوت والنص ما زالا موقوفَين حتى قرار صريح.
