# إعادة خلفية الفيديو الأصلية تحت صوت الوكيل

## النتيجة الحالية

النسخة الجديدة هي:

`dubs/snaptik-7614635067838598423-v3/final-dub-agent-ar-eg-original-bg.mp4`

مدتها **108.9 ثانية**، وتستخدم التعليق المصري المختار نفسه، دون إعادة توليد أي كلام. الخلفية **تقدير مفصول آلياً من الصوت الأصلي**، لا موسيقى جديدة ولا المسار المنطوق الأصلي مخفّضاً تحت الراوي.

النسخة السابقة بدون موسيقى محفوظة باسم `final-dub-agent-ar-eg.mp4`، ولم تتغير بصمتها.

## الطريقة التي نجحت

- تنزيل نموذج UVR متعدد النطاقات بصيغة ONNX FP16 من كائن Git عادي مثبت بكوميت، والتحقق من SHA-256 قبل تشغيله. بيانات المصدر والمعلمات في `config/uvr-background.json`.
- التشغيل محلياً على CPU بواسطة ONNX Runtime، دون Torch أو خدمات TTS أو GitHub Actions.
- تنفيذ مستقل بــNumPy/SciPy لواجهة النموذج المنشورة. يُقدّر النموذج أطياف المرافقة الموسيقية، وتُطبّق أقنعته على طور الصوت الأصلي للحفاظ على التوقيت؛ لا تُؤلف موسيقى بديلة.
- تطبيق معامل قناع `1.35` للحد من التسريب. معالجة الفيديو استغرقت نحو **142 ثانية** في هذه البيئة.
- حفظ الخلفية في `background/separated-original-background.flac`. الأوزان والبيانات الوسيطة الكبيرة داخل `.cache/` فقط؛ لا يُعاد توزيع أوزان النموذج في Git.

مضيف Git LFS أعاد خطأ TLS عند محاولة نموذج آخر، لذلك استُخدم النموذج المتاح كملف Git عادي. لا يكفي تثبيت حزمة أو تنزيل مؤشر LFS لإثبات أن النموذج يعمل.

## حدود الجودة

الفصل العصبي **ليس استعادةً مطابقة لمسار موسيقى استوديو أصلي**، خصوصاً أن المصدر شبه أحادي ومضغوط. قد يزيل بعض التفاصيل أو يترك بقايا صوتية.

استُخدم Whisper Small لفحص الخلفية وحدها ومقارنة ما تعرّف عليه مع نص الراوي. نتج نص متكرر وغير مطابق، ولم تُسترجع عبارة موثوقة للراوي الأصلي. أطول تطابق حرفي كلمة واحدة. هذا فحص مساعد فقط: عدم تعرف ASR على الكلام **لا يضمن انعدام أي تسريب**. التقرير في `background/narrator-leak-audit.json`.

## المزج

- مصدر الكلام هو **النسخة المعتمدة بدون موسيقى**، وليس الصوت الأصلي ولا نسخة تحتوي خلفية بالفعل.
- رُفعت الخلفية `+2.5 dB`، ثم وُضع خفض تلقائي مرتبط بمستوى التعليق: threshold `0.05`، ratio `3:1`، attack `20 ms`، release `500 ms`، كشف RMS.
- دخول وخروج تدريجيان للخلفية، ثم ضبط إجمالي الجهارة على نحو −16 LUFS.
- تُنسخ الصورة كما هي وتُعاد كتابة الصوت فقط. النصوص المحروقة وSRT محفوظة؛ لا تعديل لحركة الشفاه.

## التحقق الفعلي

- **3267 حزمة صورة مطابقة للمصدر بالكامل**؛ المصدر والمخرج كلاهما 108.9 ثانية.
- لا أخطاء فك ترميز؛ مسار AAC واحد، ستيريو 48 kHz.
- الجهارة المقاسة **−16.01 LUFS** والذروة **−3.33 dBTP**.
- تأخر الكلام عن النسخة المعتمدة **0 ms** في ست نوافذ مقاسة، وارتباط الموجة بين نحو 0.959 و0.989 رغم إضافة الخلفية.
- قياس الفواصل التي كانت صامتة في النسخة السابقة أكد وجود صوت خلفية فعلي فيها.
- كشف العربية في بداية المخرج باحتمال `0.999483`؛ هذا ليس مقياساً لدقة الكلمات.
- نجح **62 اختباراً مستهدفاً**. هذه قياسات تقنية، وليست شهادة استماع بشرية أو ضمان نقاء كامل للخلفية.

## إعادة التشغيل

```bash
.venv/bin/pip install -r requirements-background.txt

.venv/bin/python scripts/separate_original_background.py \
  --source library/snaptik-7614635067838598423-v3/source.mp4 \
  --output dubs/snaptik-7614635067838598423-v3/background/separated-original-background.flac \
  --work-dir .cache/separation/snaptik-work --mask-power 1.35

# افحص الخلفية أولاً؛ لا تفترض نقاءها لمجرد نجاح النموذج.
.venv/bin/python scripts/mix_original_background.py \
  --voice-video dubs/snaptik-7614635067838598423-v3/final-dub-agent-ar-eg.mp4 \
  --background dubs/snaptik-7614635067838598423-v3/background/separated-original-background.flac \
  --output dubs/snaptik-7614635067838598423-v3/final-dub-agent-ar-eg-original-bg.mp4 \
  --work-dir .cache/separation/snaptik-work/mix --background-gain-db 2.5
```

لا تغيّر `--voice-video` إلى النسخة الممزوجة عند تعديل مستوى الموسيقى؛ ارجع دائماً إلى النسخة بدون موسيقى كي لا تضيف الخلفية مرتين. تبقى مخرجات السكربت بحالة انتظار التحقق حتى تُجرى فحوص الصورة والصوت وتُحدَّث حالة المشروع.
