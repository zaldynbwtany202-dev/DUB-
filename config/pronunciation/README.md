# ملفات النطق المعتمدة للهجات

يقرأ مدقّق النطق `ar-EG` من `config/egy-pronunciation.json`. لأي لهجة أخرى، لا يخمّن لهجة بديلة ولا يطبق القاموس المصري؛ يقرأ ملفًا باسم رمز اللغة الموحّد، مثل `config/pronunciation/ar-dz.json`.

يجب ألا يُضاف مدخل إلا بعد مراجعته من متحدث/مراجع مؤهل. هيكل الملف:

```json
{
  "locale": "ar-DZ",
  "version": 1,
  "provenance": {
    "reviewer": "معرّف المراجع الذي تحقّق من الملف",
    "sources": ["مرجع أو تسجيل/قرار مراجعة موثّق"]
  },
  "lexicon": {
    "كلمة": ["قراءة صوتية مشكولة أو ملاحظة نطق معتمدة"]
  },
  "regional_variants": {}
}
```

تُعامل القيم كاقتراحات لقائمة الاستماع، ولا تُطبّق على النص أو الصوت آليًا. يَظهر الملف غير المدقّق أو المنسوب إلى رمز لهجة آخر على أنه غير مدعوم. لا يُعد وجود قاموس أو نجاح ASR إثباتًا أن الصوت ينتمي للهجة؛ الاعتماد النهائي يحتاج استماعًا بشريًا.
